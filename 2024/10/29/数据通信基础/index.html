1-1 网络参考模型

1.什么是数据？
答：数据是各种信息的载体。（访问网页，在线游戏等）;这些应用在完成其功能的过程中，所有的信息均称为数据。
数据通常是0和1组成的二进制字符串

二进制

由0和1组成，10表示二；6用二进制表示为110
平常生活中，我们会使用到十进制；0-9表示零到九，10表示十
101=1* 10^2 +0* 10^1 +1* 10^0（十进制）
110=1* 2^2 +1* 2^1 +0* 2^0(二进制)
小练习：10011100=1* 2^7 +1* 2^4 +1 2^3 +1 2^2=156

网络参考模型与标准协议

● OSI参考模型

7.应用层：对应用程序提供接口
6.表示层：进行数据格式的转换，以确保一个系统生成的应用层数据能够被另外一个系统的应用层所识别和理解
5.会话层：在通信双方建立，管理和终止对话。
4.传输层：建立，维护和取消一次端到端的数据传输过程，控制传输节奏快慢，调整数据的排序等等
3.网络层：定义编辑地址，实现数据从源到目的地的转发
2.数据链路层：将分组数据封装成帧，在数据链路上实现数据的点到点或点到多点方式的直接通信，差错检测
1.物理层：在媒介上传输比特流，提供机械的和电气的预约

传输层协议:
TCP—可靠的 (qq vx 百度网盘)
就是中断后数据不会消失，可以等有网后继续
UDP—尽力而为 (视屏语音通话)
中断后无法保证数据接收，例如通话中时断网

IP地址的表示⽅法

  1. ⼀个IPv4地址有4 byte = 32 bit （每个段8个bit）
  2. IPv4地址通常采⽤“点分⼗进制”表示。

网络地址

用于标识一个网络。通常是第一个地址：192.168.0.1
是IPv4和子网掩码通过一些运算得到。

广播地址

用于向该网络中的所有主机发送数据的特殊地址。

可用地址

可分配给网络中的节点或网络设备接口的地址。

MAC地址：绝对的定位

命令ipconfig /all查看物理地址

网络层

NAT (Network Address Translator)
网络地址转换：

  1. 使用局域网的主机向局域网出口设备IP进行请求.
  2. 出口设备会记录1.2.3.4：12345(将局域网IP转化为对应的广域网IP) –> 190.168.31.60:49728 使用该设备的公网地址和公网服务器进行数据传输

涉及到协议的有：

  • 应用层
    HTTP
    HTTPS(HTTP+TLS[安全套阶层]) # 网页 默认端口：80 443
    SSH #远程连接 22
    DNS #域名解析 53(TCP/UDP)
    ROP #远程桌面连接 3389
    SMB #文件资源共享 MS17-010 135 445
    FTP #文件传输 20 21
    SMTP POP3 #邮件传输 25 110
    mysql 3306
  • 传输层
    TCP(协议号是6) UDP(协议号是17)
  • 网络层
    IP ARP ICMP(ping：测试连通性 tracert：不仅测试连通性，还可以看网络的走向)
  • 数据链路层
    EtherNetII 802.3

现在多用TCP/IP对等模型（5层模型）：

将应用层、表示层、会话层合并为应用层，其余四层不变

数据封装及解封装

数据–>段–>包–>帧–>位
对应
应用层–>传输层(为应用层协议添加端口号)–>网络层(有数据包里的字段会说明传输层用的是TCP还是UDP)–>数据链路层（同理为网络层提供协议号来说明）–>物理层（传输介质）

下层为上层指定协议

传输层解封装

物理层–>数据链路层–>网络层–>传输层–>应用层
